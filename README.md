## ⚡ Overview

**Bharat-One UI Concepts** represents a pan-India digital design system that celebrates regional identities. It features 30+ interactive WebGL and HTML5 procedural canvas shaders capturing the cultural art, architectural silhouettes (such as the Ajanta-inspired Gateway of India), and geographical color palettes for individual Indian states and union territories.

---

## 🏛️ Interactive Showcase

- `bharat_one_*_home` — Interactive state civic home screens for Andhra Pradesh, Assam, Bihar, Chhattisgarh, Goa, Gujarat, Karnataka, Kerala, Maharashtra, Punjab, Rajasthan, Tamil Nadu, Uttar Pradesh, West Bengal, and more.
- `*_shader` — Dedicated procedural canvas animations with regional themes.
- `DESIGN.md` — Formal design system tokens including typography scales (Plus Jakarta Sans), semantic palettes, elevation, and shape constants.

For technical architecture details, see [docs/architecture.md](docs/architecture.md).

## 🚀 Running Locally

Each state directory is a self-contained, dependency-free interactive HTML5 application:
1. Open any directory (e.g. `bharat_one_karnataka_home_1/` or `tamil_nadu_shader/`).
2. Double-click `index.html` or serve via any static web server:
   ```bash
   npx serve .
   ```
