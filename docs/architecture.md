## 2. Interactive Features
- **Procedural Canvas Shaders:** Lightweight HTML5 WebGL shader canvases celebrating Indian folk motifs, monuments, and geography.
- **Citizen Portal Mockups:** State-specific landing screens customized with local administrative colors and cultural emblems.
- **Design Specifications:** Full color, typography, elevation, and component token hierarchy outlined in `DESIGN.md`.
